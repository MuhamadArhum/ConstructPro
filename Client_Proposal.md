## What We're Building

A fully custom **Construction ERP System** that manages your entire business from one dashboard — finance, HR, assets, inventory, and procurement — all secured with role-based access.

---

## Key Features

| Module | What You Get |
|--------|-------------|
| **Finance** | Income/expense tracking, Chart of Accounts, Journal Entries, Tax records, Reports |
| **HR** | Daily-wage labour (attendance + advances), Salaried employees, Payroll processing |
| **Assets** | Machinery, Vehicles, Plants — with maintenance scheduling |
| **Procurement** | Suppliers, Customers, Inventory with low-stock alerts |
| **Admin** | User & Role management, Company settings, Full audit trail |

---

## Technology Stack

- **Frontend:** React 19 + TypeScript (fast, modern UI)
- **Backend:** ASP.NET Core 8 (enterprise-grade API)
- **Database:** PostgreSQL — cloud-hosted, secure, scalable
- **Auth:** JWT with role-based permissions per user

---

## What Makes It Different

- **Role-based access** — each user only sees what they're allowed to
- **Audit logs** — every action is tracked (who did what, when)
- **Cloud-ready** — accessible from anywhere, no local server needed
- **Built from scratch** — no off-the-shelf software, fully tailored to your workflow
